# Hémisphère Simulation boursière

Un jeu de simulation de marchés financiers dans un monde fictif, inspiré des terminaux financiers professionnels. Tout tient dans un seul fichier HTML : aucun serveur, aucune installation, aucun compte.

*A fictional stock-market simulation game in a single HTML file. English interface available (button "English" at the top).*

## Jouer

- **En ligne** : ouvrez la page GitHub Pages du dépôt.
- **En local** : téléchargez `index.html` et ouvrez-le dans un navigateur récent (Chrome, Edge, Firefox, Safari).

## Ce qu'on peut faire

- Investir dans des actions, matières premières et obligations de pays fictifs (Arvénie, Norhalt, Kesh, Tavira, Îles Soryo) ou d'un monde généré au hasard.
- Suivre une économie vivante : banques centrales, inflation, guerres, météo, bulles, krachs, faillites, introductions en bourse, rumeurs et fausses nouvelles.
- Jouer en mode **dirigeant d'un pays** ou **PDG d'une entreprise cotée**.
- Avoir un métier et un salaire, payer ses impôts, utiliser des comptes enregistrés… ou tenter un paradis fiscal (à vos risques).
- Mode **débutant** (étiquettes bon / moyen / mauvais, données techniques masquées) et interface en **anglais**.

## Confidentialité et sécurité

- Le jeu fonctionne entièrement dans votre navigateur. **Aucune donnée n'est envoyée** : pas d'analyse, pas de pisteur, pas de requête réseau (à part le chargement des polices Google Fonts).
- Les parties sont enregistrées localement (localStorage / IndexedDB) et restent sur votre appareil.
- Une politique de sécurité du contenu (CSP) bloque toute connexion sortante et tout script externe.
- Les codes de sauvegarde importés sont validés et nettoyés avant d'être chargés. N'importez quand même que des codes de personnes en qui vous avez confiance.

## Avertissement

Hémisphère est un **jeu**. Les pays, entreprises, personnes, nouvelles et l'argent sont entièrement fictifs ; toute ressemblance avec des entités réelles serait fortuite. Rien dans ce jeu ne constitue un conseil financier, fiscal ou juridique.
